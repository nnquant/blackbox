# 12 · 研究地图（Research Map）

## 定义

研究地图是一棵**由研究 agent 手动维护**的研究树。每个节点有一个生命周期**阶段**（stage）、一个评审**去向**（decision）、一段短叙事（假设 / 改动 / 解读 / 结论 / 短板 / 下一步），以及至多一个到 Blackbox 实体的**绑定**（run / 分支 / 对比集 / 研究线）。

核心原则：**结构与叙事手动维护，证据自动引用。** 指标、质量门、产物、决策 note 从绑定实体读取，不存进地图；系统不自动建节点、不自动改状态、不自动切基准。

| | Lineage（分支血缘） | 研究地图 |
| --- | --- | --- |
| 数据来源 | 由 branch / run 自动推导 | agent 手动维护 |
| 粒度 | 分支与 run | 研究命题，可跨分支、跨研究线 |
| 表达 | 谁从谁派生 | 想法为什么被提出、结论是什么、下一步去哪 |

## 领域模型

- `ResearchMap`：属于 project，可选挂到一条 research；`key` 在 project 内唯一。字段：title / subtitle / description / status / `baseline_node_key`（基准指针）/ `primary_metric`（卡片主指标与分支最优 run 的选取依据）/ settings / created_by。
- `ResearchMapNode`：`key` 在地图内唯一，至多一个父节点，`position` 决定兄弟顺序。字段：title / full_title / date_label / **stage** / **decision** / hypothesis / change[] / reading[] / verdict / caveats[] / next / binding(kind,id) / refs[] / meta / created_by / updated_by。
- `ResearchMapRevision`：追加式修订记录（谁、何时、动作、字段变化与旧值）。地图与节点的每次写入、基准切换、导入都会记录。
- `Run.mode`：backtest / paper / sim / live，使跟踪、模拟、实盘阶段的证据能像回测一样绑定。

派生（不落库）：`family`（颜色族：进行中 / 采纳 / 保留 / 终止）、`is_mainline`（根到基准的路径）、`flags`（ready：结果已到未写去向；stale：假设或实验超过 14 天无进展；not_advanced：采纳后停在实验）、绑定实体的 evidence（指标、质量门、产物、decision/review note、分支最优 run）。

## 阶段与去向

阶段（有序，只向前，回退需 reason）：想法 idea → 假设 hypothesis → 实验 experiment → 验证 validation → 跟踪 tracking → 模拟 simulation → 实盘 live → 退役 retired。

去向（评审时写，可为空）：待定 pending / 保留 kept / 采纳 accepted / 否决 rejected / 被替代 superseded。

卡片颜色按去向四族，文字按阶段；基准节点深色填充加 ★；主线粗线由基准指针派生。

## 写入路径

1. `bbox map node set`：立项并绑定实体；`bbox map node decide --note`：写去向、解读、结论，并在绑定 run 上写 decision note；`bbox map node advance`：推进阶段；`bbox map baseline --reason`：切换基准。
2. `bbox map import / export`：整份 JSON/YAML 文档，按 key 幂等 upsert，`--replace` 清理。
3. SDK 同名方法；REST `/api/v1/research-maps/*`。

校验：父节点必须存在、禁止成环、绑定实体必须存在、阶段回退需 reason、同一文档 key 不重复、基准必须指向存在的节点、有子节点需 cascade 才能删除。`map lint` 做软限制（标题 ≤ 14 字、假设 ≤ 50 字、改动 / 解读 / 短板 ≤ 3 条、结论 ≤ 60 字）与一致性检查；`map status` 列出待去向、超期、采纳未推进、绑定失效、研究线内未入图的 run。

## WebUI

- 研究线页首屏内嵌地图（可全屏），分支表与最近 Run 表带「地图节点」列并可定位；侧边栏「研究地图」列出全部地图；项目页列出本项目的地图。
- 地图页：基准条（读绑定 run 指标）、去向 / 阶段两组可过滤图例、最近更新、可拖拽缩放的 SVG 树、结构化详情（结论 → 对比 → 改动 → 解读 / 短板 / 下一步 → 证据 → 子节点 → 页脚与修订）。
- WebUI 只读；修改走 CLI / SDK / API。

详细字段、命令与 API 见 `docs/research-map.md`；示例见 `examples/research-maps/quadrant-options-tree.json`。
